# Checklist de Deploy no Vercel

## Antes do deploy

- Conferir todos os links do menu.
- Atualizar telefone do WhatsApp em `assets/js/main.js`.
- Atualizar Instagram e e-mail oficiais.
- Converter materiais de `assets/docs/` para PDF, se desejado.
- Revisar politica de privacidade e termos de uso.
- Validar textos legais sobre REAL 360 Psicossocial.
- Conferir imagens e favicon.

## No Vercel

- Criar novo projeto.
- Usar a pasta `outputs/mente-infinita` como raiz do deploy.
- Como e HTML estatico, nao ha comando de build obrigatorio.
- Publicar `index.html` como entrada principal.
- Configurar dominio.
- Ativar HTTPS.

## Depois do deploy

- Testar home, menu mobile e formularios.
- Testar WhatsApp e Instagram.
- Verificar SEO title/description.
- Instalar analytics.
- Configurar Search Console.
- Criar pixels e eventos de conversao.
